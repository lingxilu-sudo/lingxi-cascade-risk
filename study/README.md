# 级联风险框架·手推课程

> 目标：学完这六课，你能不看代码、只用纸笔和计算器，把 16.5× 从头推到尾；每个数字都能说出出处。
> 方法：每课先给概念来历，再推公式，再代真实数值，最后留一个立刻能验证的核对题。
> 语体：教材式行文。所有数字与代码（`main.py`，seed=42）一致，核对脚本见 `study/verify_baseline.py`。

## 使用建议

1. 按序号读，每课末尾"动手核对"必须真的跑一遍或算一遍，再往下走。
2. 读完 0006 的"薄弱点"一节再来质疑：那份清单就是这框架的边界，质疑点大概率从里面长出来。
3. 手推时允许用计算器；不允许的是跳过单位换算。

*本课程只覆盖模型本身；论文里的市场数据（$1.2B 保险市场、WEF 成本区间）是引用，不是本模型算出来的。*
